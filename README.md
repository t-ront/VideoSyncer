# VideoSyncer

複数の動画の音声を解析して自動で同期させ、多画面分割動画として出力するWindows向けデスクトップアプリケーションです。

## 動作環境

* OS: Windows 10 / Windows 11
* ランタイム: .NET 10.0 デスクトップ ランタイム

## 事前準備（必須）

本アプリケーションを実行する前に、必ず以下の準備を行ってください。

### 1. FFmpegの配置

FFmpegをダウンロードし、アプリケーションの `Tools` フォルダ内に以下の2つのファイルを配置してください。

* `ffmpeg.exe`
* `ffprobe.exe`

### 2. Python環境のセットアップ

`Tools` フォルダ内に配置されている `setup.bat` を実行し、Python本体および必要なライブラリのインストールを完了させてください。
